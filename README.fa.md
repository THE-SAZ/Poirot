# 🔎 پوآرو — کارآگاه آی‌پی v1.0.0

> *«کارآگاه خصوصی آی‌پی‌ها؛ هیچ سرنخی از سلول‌های خاکستری او پنهان نمی‌ماند.»*

کنسول شناسایی تمام‌طیفی آی‌پی + **آزمایشگاه نشت LEAK IP 2026** روی **کره واقعی و چرخان زمین** (پروژه‌کشن Globe در MapLibre GL با تایل‌های CARTO / OpenStreetMap / ماهواره‌ای Esri + فال‌بک خودکار Leaflet). **پایدار، بدون باگ، آماده تولید.**

## 🎯 چه‌چیز در v1.0.0 جدید است

### 🐞 باگ‌های بحرانی رفع‌شده
- **خطای سینتکس LeakLab** (`push({...};}` بدون پرانتز بسته) که کل اسکریپت را می‌کشت — **رفع شد**.
- **`map.loaded()`** با `try/catch` و `typeof` ایمن شد تا در MapLibreهای قدیمی کرش نکند.
- **هندلر سراسری خطا** اضافه شد تا باگ‌های احتمالی به‌جای صفحه سفید، توست نشان دهند.
- **`Object.assign`** اشتباه رفع شد.
- همه کتابخانه‌های CDN با چک `typeof` و فال‌بک Leaflet ایمن شدند.

### ✨ امکانات جدید
- 🌓 تم **تیره / روشن / خودکار** (بر اساس تم سیستم).
- 🎨 **۶ رنگ اکسنت** (سیان، مجنتا، لایم، طلایی، ویولت، مرجانی).
- 🔤 **کنترل تایپوگرافی**: اسلایدر اندازه فونت، اسلایدر گردی گوشه‌ها.
- 🎵 **افکت‌های صوتی** اختیاری.
- 🔍 **مقایسه دو آی‌پی** کنار هم (حالت diff).
- 🏷️ **سیستم برچسب‌گذاری** روی پرونده‌ها.
- 📊 **تایم‌لاین** بایگانی بر اساس تاریخ.
- 📁 **فیلترهای پیشرفته**: بازه زمانی، دقت، برچسب.
- 🌍 **خروجی KML** برای Google Earth.
- 📷 **اسکرین‌شات از نقشه** (دانلود PNG).
- 🔗 **اشتراک URL** با پارامتر `?ip=` (اسکن خودکار).
- 🔔 **نوتیفیکیشن PWA** پس از اتمام اسکن.
- ⌨️ **میانبرهای صفحه‌کلید**: `Ctrl+M` آی‌پی خودم، `Ctrl+L` آزمایشگاه نشت، `Ctrl+,` تنظیمات، `Ctrl+S` اسکرین‌شات، `F` تمام‌صفحه.
- 🛡️ **حالت خصوصی** (سانسور جزئیات حساس در خروجی‌ها).
- 🔒 غیرفعال‌سازی کاوش WebRTC / درخواست GPS به‌طور پیش‌فرض.
- ⚙️ تنظیم تایم‌اوت و حداکثر منابع اسکن.
- 💾 **پشتیبان‌گیری خودکار** از بایگانی.
- ❓ مودال راهنمای داخلی.
