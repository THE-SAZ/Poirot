# 🔎 Пуаро — детектив по IP v1.0.0

> *«Частный детектив IP-адресов — ничто не ускользнёт от его серых клеточек.»*

Консоль полной IP-аналитики + **лаборатория утечек LEAK IP 2026** на **настоящем вращающемся глобусе** (глобус-проекция MapLibre GL с тайлами CARTO / OpenStreetMap / спутником Esri + автоматический фолбэк Leaflet). **Стабильно, без багов, готово к продакшену.**

## 🎯 Что нового в v1.0.0

### 🐞 Критические баги исправлены
- **Синтаксическая ошибка в LeakLab** (`push({...};}` без закрывающей скобки), убивавшая весь скрипт — **исправлена**.
- **`map.loaded()`** обёрнут в `try/catch` и `typeof`, чтобы не падать на старых версиях MapLibre.
- **Глобальный обработчик ошибок** — будущие баги теперь показывают тост, а не белый экран.
- **`Object.assign`** исправлен.
- Все CDN-библиотеки защищены `typeof` и автофолбэком Leaflet.

### ✨ Новые возможности
- 🌓 Темы **тёмная / светлая / авто** (следует за системной).
- 🎨 **6 акцентных цветов** (циан, маджента, лайм, золото, фиолет, коралл).
- 🔤 **Управление типографикой**: слайдер размера шрифта, радиуса углов.
- 🎵 Опциональные **звуковые эффекты** (Web Audio API).
- 🔍 **Сравнение двух IP** рядом (diff-режим).
- 🏷️ **Система тегов** для дел.
- 📊 **Таймлайн** архива по датам.
- 📁 **Продвинутые фильтры**: время, точность, теги.
- 🌍 **Экспорт KML** для Google Earth.
- 📷 **Скриншот карты** (скачивание PNG).
- 🔗 **Шеринг URL** с параметром `?ip=` (автоскан при открытии).
- 🔔 **PWA-уведомления** по завершении скана.
- ⌨️ **Горячие клавиши**: `Ctrl+M` мой IP, `Ctrl+L` лаборатория, `Ctrl+,` настройки, `Ctrl+S` скриншот, `F` полный экран.
- 🛡️ **Приватный режим** (цензура деталей в экспортах).
- 🔒 Отключение WebRTC-зонда / запроса GPS по умолчанию.
- ⚙️ Настройка таймаута и числа источников.
- 💾 **Авто-бэкап** архива.
- ❓ Встроенный модал помощи.

## ✨ Основные возможности
| Слой | Методы |
|---|---|
| **Гео-консенсус** | 5 параллельных источников + голосование страна/город + медиана координат + **радиус ошибки (км)** + % согласия |
| **Сетевая идентичность** | ISP / Org / ASN + BGP-префикс (Team Cymru) + обратный PTR через Cloudflare DoH |
| **Безопасность** | Tor-выход, прокси, VPN, хостинг + выводы |
| **LEAK LAB 2026** | публичный и локальный WebRTC • часовой пояс • язык • путь DNS • **точные GPS-координаты** с Δ по формуле гаверсинусов + дуга на глобусе • оценка защиты • JSON-экспорт |
| **Детектив модема** | оценка модема по PTR + база стран + зонд шлюза + WebRTC (с причинами) |
| **Отпечаток** | браузер/ОС/GPU/экран/языки/соединение/батарея + часы часового пояса цели + расстояние + дуга «вы ← цель» |
| **Глобус** | нумерованные метки с **редактированием/удалением/выбором на карте**, GPS-метка, дуги большого круга, пульс-кольца, автовращение, стили неон и спутник |
| **Приложение** | трёхъязычное (FA/EN/RU) • панель настроек с 7 вкладками • офлайн-PWA • архив с поиском/фильтрами/таймлайном + JSON/CSV/KML экспорт/импорт • киберпанк-тема |
